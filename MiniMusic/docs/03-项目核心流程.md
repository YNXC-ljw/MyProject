# 核心流程(12 条)

> 每条流程都写成"触发 → 调用链 → 涉及模块 → 技术点"。函数名请对照你自己的代码核对,不一致的地方以你的代码为准。

## 流程 1:程序启动与数据恢复

- **触发**:双击运行程序
- **调用链**
  1. `main()`:创建 `QApplication`
  2. 用 `QSharedMemory` 做单实例检测(已在运行则提示并退出)
  3. 创建主窗口 `QQMusic`
  4. 构造函数中依次:`ui->setupUi(this)` → 初始化界面 → 初始化数据库 → 从数据库恢复歌曲 → 初始化播放器 → 连接信号槽
  5. `show()` 显示窗口,进入 `a.exec()` 事件循环
- **涉及模块**:程序入口、主窗口、数据层、播放核心层
- **技术点**:单实例检测、对象树、事件循环

## 流程 2:添加本地音乐

- **触发**:点击"添加本地音乐"按钮
- **调用链**
  1. 主窗口的 `on_addLocal_clicked()`
  2. 创建 `QFileDialog`,设置为可多选、加 MIME 过滤,打开指定目录
  3. 用户确认后拿到 `QList<QUrl>`
  4. 调 `musicList.addMusicByUrl(urls)`
  5. 逐个文件:`QMimeDatabase` 判断是否音频 → `QSet` 判断是否已加载(去重)→ 构造 `Music` 对象并解析元数据 → 加入歌曲集合
  6. 调 `localPage->reFresh()` 刷新界面
- **涉及模块**:UI 层(按钮 / 对话框)、业务层、数据层
- **技术点**:MIME 类型过滤、QSet 去重、元数据解析、界面刷新

## 流程 3:左侧导航切页

- **触发**:点击左侧导航按钮(BtForm)
- **调用链**
  1. `BtForm::mousePressEvent()`:修改自己的样式 → `emit click(id)`
  2. `QQMusic::onBtFormClick(int id)`
  3. 用 `findChildren<BtForm*>()` 找到所有导航按钮,把不是当前按钮的高亮清掉
  4. 只保留当前按钮的跳动动画
  5. `ui->stackedWidget->setCurrentIndex(id - 1)` 切换右侧页面
- **涉及模块**:UI 层、业务层
- **技术点**:自定义控件、信号槽、QStackedWidget 多页面

## 流程 4:播放 / 暂停

- **触发**:点击播放按钮
- **调用链**
  1. `onPlayClicked()`
  2. 读取 `player->state()`
  3. 按状态分流:`Playing` → `pause()`;`Paused` → `play()`;`Stopped` → `play()`
  4. 播放器状态变化发出 `stateChanged`,主窗口据此更新按钮图标
- **涉及模块**:UI 层、业务层、播放核心层
- **技术点**:状态机、信号驱动的界面更新

## 流程 5:播放整页歌曲 / 双击播放某一首

- **触发**:点击"播放全部"按钮,或双击列表中的某一行
- **调用链**
  1. `CommonPage` 发出信号:`playAll(pageType)` 或 `playMusicByIndex(this, 行号)`
  2. 主窗口接收后确定是哪个页面
  3. 进入播放逻辑:`playList->clear()` 先清空旧队列
  4. 调 `addMusicToPlayList(musicList, playList)`:按页面类型从全部歌曲里筛出本页歌曲加入队列
     - 我喜欢页:只加 `isLike` 为真的
     - 最近播放页:只加 `isHistory` 为真的
     - 本地下载页:全部加入
  5. `playList->setCurrentIndex(行号)` 定位到目标歌曲
  6. `player->play()` 开始播放
- **涉及模块**:UI 层、业务层、数据层、播放核心层
- **技术点**:页面复用(枚举区分)、播放队列重建、界面列表与播放队列的索引对齐

## 流程 6:上一曲 / 下一曲 / 播放模式切换

- **触发**:点击上一曲、下一曲或播放模式按钮
- **调用链**
  1. 上一曲 / 下一曲:直接调 `playList->previous()` / `playList->next()`
  2. 播放模式:在"列表循环 → 随机 → 单曲循环"之间循环,调用 `playList->setPlaybackMode(...)`
  3. 模式变化后播放列表发出 `playbackModeChanged`,主窗口据此更换按钮图标和提示文字
- **涉及模块**:UI 层、业务层、播放核心层
- **技术点**:QMediaPlaylist 接口、枚举状态循环、信号回调

## 流程 7:播放进度、时长、封面同步

- **触发**:播放过程中播放器发出信号
- **调用链**
  1. `durationChanged(qint64)` → 更新歌曲总时长显示
  2. `positionChanged(qint64)` → 更新当前时间显示,并让进度条按比例前进
  3. `metaDataAvailableChanged(bool)` → 读取 `metaData("Title"/"Author"/"ThumbnailImage")`,更新歌名、歌手、封面
- **涉及模块**:业务层、播放核心层、UI 层
- **技术点**:信号驱动界面、元数据 API、封面图片显示

## 流程 8:进度条拖动定位(seek)

- **触发**:在进度条上按下并拖动,然后松开
- **调用链**
  1. 自定义进度条重写鼠标按下 / 移动 / 释放事件
  2. 拖动时按鼠标横坐标更新已播放部分的宽度
  3. 松开时发出信号 `setMusicSliderPosition(比例)`
  4. 主窗口收到后计算 `player->setPosition(比例 × 总时长)`
  5. 播放器回传新的 `positionChanged`,进度条数值收敛一致
- **涉及模块**:UI 层、业务层、播放核心层
- **技术点**:鼠标事件重写、比例换算、界面与播放器的双向同步

## 流程 9:音量调节与静音

- **触发**:点击音量按钮,或在音量面板上拖动 / 点击静音
- **调用链**
  1. 点击音量按钮:计算弹窗应显示的坐标 → `move()` 并 `show()` 音量面板
  2. 音量面板通过事件过滤器接管音量条上的鼠标按下 / 移动 / 松开
  3. 按纵坐标比例算出音量值,更新滑块位置和百分比文字
  4. `emit setMusicVolume(int)` → 主窗口调用 `player->setVolume(...)`
  5. 点击静音按钮:切换状态 → `emit setSilence(bool)` → `player->setMuted(...)`
- **涉及模块**:UI 层、业务层、播放核心层
- **技术点**:事件过滤器、坐标换算、弹出窗口(Popup)、信号上抛

## 流程 10:收藏与最近播放

- **收藏(取消收藏)**
  1. 列表行控件上的红心按钮被点击,切换图标 → `emit setIsLike(bool)`
  2. 列表页收到信号后转发,并补上歌曲 ID:`updateLikeMusic(bool, musicId)`
  3. 主窗口根据 ID 找到歌曲对象,修改其收藏状态
  4. 依次刷新"我喜欢 / 本地下载 / 最近播放"三个页面
- **最近播放**
  1. 播放列表换歌时发出 `currentIndexChanged(index)`
  2. 主窗口根据当前页面和索引拿到歌曲 ID,再找到歌曲对象
  3. 把它的"已播放"标记置为真
  4. 刷新"最近播放"页面
- **涉及模块**:UI 层、业务层、数据层
- **技术点**:三层信号转发、索引到 ID 的映射、状态同步

## 流程 11:歌词解析与同步显示

- **触发**:切换歌曲 / 播放进度推进
- **调用链**
  1. 歌曲切换:`metaDataAvailableChanged` → 按歌曲 ID 找到歌曲 → 取同名 `.lrc` 路径 → 调用歌词窗的解析函数
  2. 解析:打开文件 → 逐行读取 → 从每行拆出时间 `[分:秒.毫秒]` → 换算成毫秒 → 存入歌词行数组
  3. 播放推进:`positionChanged` → 把当前播放位置传给歌词窗
  4. 显示:按时间查找当前应唱的那一行,显示当前行以及前后各 3 行,当前行高亮
- **涉及模块**:业务层、数据层(文件)、UI 层
- **技术点**:文件解析、时间区间查找、驱动与显示分离

## 流程 12:退出与数据保存

- **触发**:点击关闭按钮,或从系统托盘选择退出
- **调用链**
  1. 关闭按钮:仅隐藏窗口到托盘,不退出程序
  2. 托盘菜单"退出":真正退出
  3. 调 `musicList.writeToDB()`:遍历所有歌曲,已在数据库中的更新收藏 / 历史状态,不在的插入
  4. `sqlite.close()` 关闭数据库连接
  5. `close()` 退出程序
- **涉及模块**:业务层、数据层
- **技术点**:SQLite 持久化、存在性判断后更新或插入、资源释放
