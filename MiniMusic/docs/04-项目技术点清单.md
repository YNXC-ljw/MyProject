# 技术点清单

> 用法:面试前照着这张表逐个自问"这个技术点我在哪里用了、怎么实现的"。第三列要是你能张嘴说出来的程度,才算过关。

| 技术点 | 用在哪里 | 实现要点 | 可能被追问 |
| --- | --- | --- | --- |
| 自定义控件开发 | BtForm、RecBox、RecBoxItem、ListItemBox、MusicSlider、VolumeTool、LrcPage | 用 Designer 建界面再"提升为"自定义类,内部自管理子控件,对外只暴露 `setXxx` 接口和信号 | 为什么不用自带控件?提升为是什么机制? |
| 信号槽解耦 | 整个项目 | 子控件不认识数据库和播放器,只发信号;主窗口统一接收处理 | 信号槽和回调的区别?连接类型有哪些? |
| 三层信号转发 | 收藏功能 | 列表行控件发信号 → 列表页补上歌曲 ID 后转发 → 主窗口处理 | 为什么行控件不直接改数据? |
| 事件过滤器 | VolumeTool 音量条、RecBoxItem 悬停 | `installEventFilter`,在 `eventFilter` 里处理 Enter/Leave 与鼠标事件,处理完 `return true` | 为什么不用重写事件?返回值含义? |
| 鼠标事件重写 | MusicSlider、BtForm、主窗口拖拽 | 重写按下 / 移动 / 释放,做坐标换算与界面更新 | 坐标怎么换算?越界怎么处理? |
| 自绘 | VolumeTool 的三角提示 | `QPainter` + `QPolygon` 手动绘制多边形 | 为什么不用控件?paintEvent 机制? |
| 动画 | 导航按钮音符跳动、推荐位悬停上移、歌词窗弹出收起 | `QPropertyAnimation` 修改 `geometry`,设置时长 / 起止值 / 循环次数,`finished` 后收尾 | 动画对象谁释放?怎么无限循环? |
| 无边框窗口 | 主窗口、音量面板、歌词窗 | `FramelessWindowHint` + 透明背景 + `QGraphicsDropShadowEffect` 阴影 | 为什么透明背景?阴影半径过大有什么问题? |
| 多媒体播放 | 播放核心 | `QMediaPlayer` + `QMediaPlaylist`,按状态机播放 / 暂停,靠信号回传进度与元数据 | Qt6 有什么变化?多格式怎么支持? |
| 播放队列与索引对齐 | CommonPage | 播放前清空队列,按页面类型重新装歌;队列顺序与界面行号一致,因此双击第几行就播第几首 | 为什么不把所有歌都放一个队列? |
| 进度条定位(seek) | MusicSlider | 拖动本地先画,松手时发比例信号,主窗口换算成毫秒调 `setPosition` | 拖动时和自动更新会打架吗? |
| 音量控制 | VolumeTool | 事件过滤器 + 比例换算 + 静音切换,通过信号交给主窗口设置播放器 | 为什么音量面板用 Popup? |
| 元数据解析 | Music | 用播放器读取标题 / 作者 / 专辑 / 时长 / 封面,缺失时从文件名解析 | 解析阻塞主线程怎么办? |
| LRC 解析与同步 | LrcPage | 逐行解析时间戳并统一换算成毫秒,播放时按时间查找当前行,显示前后各 3 行 | 解析和显示的驱动分别在哪里? |
| SQLite 持久化 | Music、MusicList | 建表、参数化 SQL、`SELECT EXISTS` 判断后更新或插入、退出保存启动恢复 | 为什么用数据库不用文件?怎么防注入? |
| 数据去重 | MusicList | 用 `QSet` 保存已加载的文件路径,查找平均 O(1) | 为什么不用遍历查找?重启后会怎样? |
| 数据模型设计 | Music、MusicList | 用 UUID 做唯一标识,集合类实现迭代器以支持范围 for | 为什么不用文件路径做 ID? |
| 系统集成 | 程序入口、主窗口 | `QSystemTrayIcon` 做托盘、`QSharedMemory` 做单实例 | 托盘关闭为什么不退出程序? |
| 资源与发布 | 资源文件、打包 | `.qrc` 管理图片资源;release 编译后用 windeployqt 收集依赖 | 为什么拷 exe 到别的电脑跑不了? |
