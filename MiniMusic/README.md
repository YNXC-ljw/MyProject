# MiniMusic

一个基于 **C++ 与 Qt Widgets** 的本地音乐播放器,界面参考 QQ 音乐风格。

项目把 Qt 的界面开发、自定义控件、动画、信号槽、多媒体播放、多线程与 SQLite 持久化串成了一条完整的链路:左侧导航切换页面,右侧管理本地歌曲,底部控制播放,并支持 LRC 歌词同步显示与播放记录记忆。

## 功能特性

**歌曲管理**

- 添加本地音乐:文件对话框多选,按 MIME 类型过滤音频文件,用 `QSet` 按路径去重
- 三个列表页:我喜欢、本地音乐、最近播放(同一套页面的三种筛选视图)
- 收藏:列表行上的红心按钮,状态实时同步到三个页面并写入数据库
- 最近播放:播放过的歌曲自动进入"最近播放"页

**播放控制**

- 播放 / 暂停、上一曲 / 下一曲
- 三种播放模式:顺序播放、随机播放、单曲循环
- 进度条拖动定位(seek),当前播放时间与总时长同步显示
- 音量调节面板、静音开关
- 播放全部、双击列表任意一行播放

**歌词与界面**

- LRC 歌词解析,当前行高亮,同时显示前后各三行,歌词窗口带动画弹出与收起
- 无边框窗口、窗口阴影、可拖拽移动
- 自定义控件与 `QPropertyAnimation` 动画(导航按钮跳动的音符、推荐位悬停上移)

**系统集成**

- 系统托盘:关闭按钮只隐藏窗口,托盘菜单里才是真正退出
- `QSharedMemory` 单实例检测,避免程序多开

## 技术栈

| 项 | 说明 |
| --- | --- |
| 语言 | C++11 |
| 界面 | Qt Widgets(Qt Designer 设计界面 + 代码封装自定义控件) |
| 播放 | `QMediaPlayer` + `QMediaPlaylist` |
| 数据 | SQLite(Qt SQL 模块,`musicInfo` 单表) |
| 多线程 | `QThread` + 工作对象(`MusicWorker`),子线程负责解析音频元数据 |
| 构建 | qmake(项目文件 `MiniMusic.pro`) |
| 开发环境 | Qt 5.14.2 MinGW 64-bit(课程使用的环境) |

> 注意:代码用到了 `QMediaPlaylist`,而新版 Qt 的 QtMultimedia 已经不再提供这个类。仓库里如果出现 Qt6 的构建目录,说明曾经用 Qt6 的 kit 打开过;要真正迁移到 Qt6,需要把播放队列换成自己维护的队列(详见 `docs/05-项目不足或优化点.md`)。

## 快速开始

1. 克隆仓库并进入 `MiniMusic` 目录
2. 用 Qt Creator 打开 `MiniMusic.pro`,选择一个带 `multimedia` 和 `sql` 模块的 Qt 版本作为构建套件
3. 构建并运行

也可以走命令行(qmake + MinGW):

```bash
qmake MiniMusic.pro
mingw32-make
```

程序不会自带歌曲,首次运行后点击界面右下角的"添加本地音乐"按钮选择音频文件即可,支持 mp3、flac、wav 三种格式。收藏与播放记录保存在程序运行目录下的 `MiniMusic.db` 中。

```text

├── main.cpp                 程序入口:单实例检测 + 启动主窗口

├── listitem.*               列表中的单行歌曲控件

├── volumetool.*             音量调节面板

├── recbox.* / recboxitem.*  推荐页的容器与推荐位元素
├── music.*                  单曲数据模型(元数据解析 + 写库)

├── image/                   界面图片资源
├── music/                   示例音频文件
└── docs/                    项目笔记(见下方目录)
```

## 模块划分

| 模块 | 职责 |
| --- | --- |
| 主窗口 `Widget` | 程序调度中心:初始化界面/播放器/数据库,连接并处理所有信号槽 |
| 列表页 `CommonPage` | 三个列表页的共同实现:按页面类型筛选歌曲、刷新列表、组装播放队列 |
| 歌曲模型 `Music` | 描述一首歌:解析元数据、提供歌词路径、把状态写进数据库 |
| 歌曲集合 `MusicList` | 管理全部歌曲:路径去重、按 ID 查找、启动时从数据库恢复 |
| 解析工作对象 `MusicWorker` | 在子线程里把文件路径解析成 `Music` 对象,完成后用信号把结果交回主线程 |
| 自定义控件 | `BtForm`、`RecBox`、`RecBoxItem`、`ListItem`、`MusicSlider`、`VolumeTool`、`LrcPage` |

界面层不直接操作播放器和数据库,只发信号;主窗口统一接收处理,再调数据层和播放器,最后刷新界面。详细说明见 `docs/01-项目架构与模块.md`。

## 已知问题

当前版本仍有一些待修的问题,比较关键的有:

- 解析工作线程在第一批任务结束后就退出了,第二次点"添加本地音乐"不会生效
- 播放队列和界面列表靠"顺序一致"关联,页面刷新后索引可能错位
- 收藏与播放记录只在退出时写库,退出路径没有统一收口
